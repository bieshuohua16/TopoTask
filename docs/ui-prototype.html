原型 方向

这次改了什么

原型仅供参考视觉与结构，不改动现有后端与 API。确认方向后再落到 templates / CSS。

01 全站框架

  • 侧栏可折叠（68px 图标态），项目列表增加未完成数与阶段色点，列表内可筛选
  • 顶部搜索改为主入口，保留 / 快捷键；页面标题、面包屑、操作区垂直对齐
  • 统一间距刻度 4/8/12/16/24，圆角两档，阴影收敛为「边框 + 轻投影」
  • 新增等宽数字字体，金额、计数、日期不再跳动

02 项目总览

  • 新增「阶段分布」条，直接看到 4 个售前阶段的项目与任务负载
  • KPI 卡增加迷你趋势与口径说明，逾期数量用红色语义色
  • 项目卡重构：阶段进度条 + 距截止 + 任务/图/节点计数，卡片等高
  • 「即将到期」改为日期轴，逾期节点前置；右栏固定 300px 不抢主区

03 阶段看板

  • 列头显示阶段色、任务数、WIP 上限；列底给拖拽占位提示
  • 卡片信息分层：项目归属 → 标题 → 优先级/截止/图纸 → 负责人
  • 顶部增加「全部项目 / 显示已完成」与整体负载摘要

04 拓扑图库 / 项目 · 拓扑图

  • 缩略图统一为「节点—连线」骨架绘制，按类型使用不同线型，不再用占位图
  • 卡片显示节点数、关联任务、待跟进；操作按钮收进 hover，降低噪音
  • 增加类型筛选、搜索、网格/列表切换

05 项目工作台

  • 阶段进度从内容区提到页头（横向 4 步），首屏内容整体上移约 120px
  • 概览增加「项目动态」时间线；任务完成率改为环形图 + 3 项关键指标
  • 任务抽屉固定 360px，支持收起；空状态给出「选中任务」的明确引导
  • 任务行信息分层：优先级色条、标题、阶段、截止、标签、图纸、负责人

06 设备清单 / 模板库

  • 汇总条 4 项对齐表格口径，金额右对齐等宽；表格粘性表头
  • 类别色标签统一（服务器/存储/网络/安全/其他），关联拓扑可点
  • 工具栏改为「搜索 → 筛选 → 批量/导出/新增」的固定顺序

07 拓扑编辑器

  • 顶栏合并为一条：返回、图纸名与保存态、撤销/重做、工具、缩放、网格吸附、演示/导出、AI 优化
  • 左侧沿用现有「图形模具 / 素材库」结构，基础图形与网络设备 13 项名称与现有编辑器一致，另加搜索与最近使用
  • 画布：节点按类型着色、选中锚点、待跟进虚线框与角标、小地图、缩放浮层
  • 右侧保持「属性 / AI 助手」两个页签，属性内包含设备关联与关联任务
  • 底部状态栏常驻节点/连线数、坐标、选中数、缩放与待跟进数量

08 AI 助手抽屉

  • 右侧 420px 抽屉 + 遮罩，不挤压主区；顶部显式展示上下文（项目 / 阶段 / 图纸 / 选中对象）
  • 回答带引用依据（招标文件条款 / 设备清单 / 当前图纸），缺口检测以分级列表呈现
  • 结果可直接转动作：在图中标注、生成整改任务，任务以「待确认草稿」形式回写，避免误写
  • 快捷提示词 + Enter 发送，Esc / 点击遮罩关闭；编辑器与任务台共用同一抽屉

09 一致性与可访问性
