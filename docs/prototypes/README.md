# TopoTash 速记 · 设计稿与原型

## 最终形态

| 维度 | 结论 |
|---|---|
| 入口 | 桌面浮窗（pywebview，无边框 / 置顶 / 托盘 / 全局热键 `Ctrl+Alt+N`） |
| 输入 | 一行文本，`Enter` 记一条待办 |
| `+` | 行首 → 新建项目 |
| `@` | 项目选择器；选中后**立刻切换**，下方显示该项目待办 |
| `#` | **售前阶段**选择器（需求调研 / 方案编写 / POC 验证 / 招投标） |
| 记录落点 | 项目**任务**（`tasks` 表），不另开一套进展流水 |
| 撤销 | `Ctrl+Z` 或 toast 上的「撤销」 |
| 窗口 | `－` 收起成悬浮标题栏；`×` 收进托盘；托盘右键菜单 |
| 任务栏 | 不占（`WS_EX_TOOLWINDOW`） |

## 可点的 Demo

`capture-demo.html` —— 双击即开，单文件、无依赖、不联网，是 v0.8 的**手感 demo**：

- 直接写 = 记进展；`+` = 新建项目；`@` = 切项目；`#` = 类型
- Tab 补全、AI 延迟模拟、HUD 统计

它记录的是「进展」，和现在的「记待办」不同，**只作历史参考**；正式版以 `docs/CAPTURE.md` 为准。

## 已知边界

- DirectX 独占全屏下无法显示；无边框全屏正常
- 多显示器 / 125% 缩放按屏幕坐标存位置
- 窗口尺寸被夹在 `MIN_EXPANDED = (380, 520)` 以上，避免标题栏按钮被裁
